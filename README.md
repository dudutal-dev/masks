# מסכות (Masks)

אפליקציית משחקי תפקידים לזוג. PWA ללא שרת: הכול נשמר במכשיר בלבד.

- **סצנה** = במה ואביזרים, **קלף תפקיד סודי** לכל אחד (דמות, איך לשחק, מטרה סודית, משפט פתיחה; מוסרים את הטלפון וכל אחד רואה רק את שלו), ושלושה **שלבים** שמסלימים. השלב האחרון פתוח: הסצנה ממשיכה לאן שהזוג לוקח אותה.
- **ערב** = שתי סצנות (קלה יותר ולוהטת יותר) וכרטיס **יציאה מהדמות**.
- **מחולל סצנות**: מקום × דמויות × טוויסט לסצנה מאולתרת.
- היוזם/ת והמגיב/ה: קבוע, מתחלף כל סצנה, או הגרלה.
- גבולות לפי קטגוריות (כל אחד מסמן לבד, רק החיתוך נכנס), מילת עצירה שמוציאה מהדמות.
- טיימר, מצב טלוויזיה 16:9 (קלפי התפקיד לעולם לא מוצגים על המסך הגדול), הקראה, תמונות וסרטונים לכל סצנה, פרומפטים באנגלית, גיבוי מלא לקובץ, ממשק בעברית ובאנגלית.

## מבנה

- `index.html`, `css/style.css`, `js/app.js`: המנוע (משותף עם קטיפה ונשימה).
- `js/cards-data.js`: קטגוריות, תקצירי הסצנות (כרטיסים), קוביות המחולל.
- `js/scenes.js`: הפירוט הדו-לשוני של כל סצנה (במה, אביזרים, קלפי תפקיד, שלבים).
- `js/cards-en.js`: תקצירים באנגלית לפרומפטים ולממשק האנגלי.
- `js/i18n.js`: תרגום הממשק לאנגלית.
- `js/media.js`, `js/backup.js`: מדיה במכשיר וגיבוי.

## פריסה

כל דחיפה ל-`main` מפרסמת ל-GitHub Pages דרך `.github/workflows/pages.yml`. בכל שינוי מעלים את `APP_VERSION` ב-`js/app.js`, את `version.json`, את `?v=` ב-`index.html` ואת שם המטמון ב-`sw.js`.
