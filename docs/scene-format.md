# מבנה קובץ סצנות (JSON) לייבוא למסכות

ייבוא: **עוד ← ייבוא סצנות מקובץ JSON**. באותו חלון: **הורדת תבנית JSON** (דוגמה מלאה) ו**ייצוא הסצנות שלכם** (לגיבוי או לעריכה מחוץ לאפליקציה). סצנה עם אותו `id` מחליפה את הקיימת.

## המבנה

```json
{"scenes": [
 {
  "id": "slug-ייחודי (אותיות לטיניות, ספרות, מקפים)",
  "cat": "מזהה קטגוריה מהרשימה למטה",
  "lvl": 1,
  "min": 25,
  "img": "mask",
  "he": {
   "title": "שם הסצנה",
   "premise": "תקציר של משפט-שניים: מי, איפה, מה קורה.",
   "setting": "הבמה: החדר, האור, מי עומד איפה בתחילת הסצנה.",
   "props": "אביזרים.",
   "D": { "who": "הדמות של היוזם/ת", "how": "איך לשחק אותה", "secret": "המטרה הסודית: ...", "opener": "״משפט פתיחה״" },
   "S": { "who": "הדמות של המגיב/ה", "how": "איך לשחק אותה", "secret": "המטרה הסודית: ...", "opener": "״משפט פתיחה״" },
   "beats": ["שלב 1", "שלב 2", "שלב 3"]
  },
  "en": { "...אותו מבנה באנגלית (לא חובה)..." },
  "shot": "תיאור צילומי באנגלית לפרומפטים של תמונה וסרטון (לא חובה)"
 }
]}
```

- `lvl`: 1 (חימום), 2 (בינוני), 3 (אינטנסיבי). הערב בונה סצנה קלה ואז לוהטת לפי הרמה.
- `min`: משך משוער בדקות (מוצג בכרטיס).
- `img`: איור מהרשימה: blindfold, kneel, figure, hourglass, rope, back, shoe, garter, hand, gloves, lips, tongue, whisper, eye, mask, headphones, collar, ring, leash, cuffs, scarf, whip, paddle, candle, ice, feather, clothespin, toy, lock, key, chain, heart, bed, chair, mirror, lamp, camera, phone, blanket, bath, oil, spoon, brush, hanger, speech, cup, dice, stopwatch, marker, music, water, flame, stop, gear, corset, bite.
- `beats`: רשימה של שלבים (בדרך כלל שלושה). כל שלב מוצג לבד עם כפתור "השלב הבא".
- `D` = היוזם/ת (מי שפותח/ת את הסצנה), `S` = המגיב/ה. מי מהשניים הוא D נקבע במסך הבית (קבוע / מתחלף כל סצנה / הגרלה).

## משתנים בטקסט

- `{D}` ו-`{S}`: שמות היוזם/ת והמגיב/ה, כפי שהוגדרו באפליקציה.
- `{d:זכר|נקבה}`: בוחר לפי מין היוזם/ת. `{s:זכר|נקבה}`: לפי מין המגיב/ה. אפשר לקנן: `{d:תן|תני} ל{S} פקודה. {s:הוא מבצע|היא מבצעת} מיד.`
- בקלפי התפקיד נוח לכתוב בסגנון ניטרלי (שמות פועל: "לבחור שם חדש", "לא להסגיר") כדי לא להזדקק להטיות.
- באנגלית אותם משתנים עובדים; בפרומפטים `{D}`/`{S}` הופכים ל-"the man"/"the woman" לפי מי יוזם.

## פרומפטים לתמונה ולסרטון

האפליקציה בונה את הפרומפטים בעצמה, ברשימה **"להעתקה ופרומפטים"**, לכל סצנה בשני נוסחים (הגבר יוזם / האשה יוזמת):

- **פרומפט תמונה**: הפריים (מתוך `shot` אם קיים, אחרת מהתקציר האנגלי), שורת אנשים ואנטומיה, וסגנון.
- **פרומפט סרטון**: שלושה שלבים (START / MOVE / END FRAME) שנגזרים מ-`shot`: המשפטים הראשונים הם ההתחלה, האמצע הוא התנועה, והמשפט שמתחיל ב-"End frame:" הוא הפריים האחרון. אחריהם: אנשים, מה לשמר מתמונת הייחוס, סגנון, הנחיות וידאו וחוקים.

לכן `shot` הוא השדה שקובע את איכות הפרומפטים: תיאור צילומי באנגלית של מי עומד איפה, מה זז, ואיך הקליפ נגמר, עם משפט אחרון שמתחיל ב-"End frame:". בלי `shot`, הפרומפטים נבנים מהתקציר באנגלית (`en.premise`), ובלעדיו מהתקציר בעברית.

את הסגנון הכללי (תאורה, מצלמה, מה לשמר) עורכים פעם אחת ב"בסיס הפרומפט" באותו מסך, והוא חל על כל הסצנות. תמונות וסרטונים שיצרתם מעלים מאותה רשימה, לכל נוסח בנפרד.
